## Version Format

### Types of changes
- **Added** for new features.
- **Changed** for changes in existing functionality.
- **Deprecated** for soon-to-be removed features.
- **Removed** for now removed features.
- **Fixed** for any bug fixes.
- **Security** in case of vulnerabilities.

### Example

```markdown
## [1.0.0] - 2024-12-01

### Added
- Auto bookkeeping via App Intents
- Intelligent category classification
- Transaction list and details view
- Basic statistics dashboard
- User onboarding flow
- Local data storage with SwiftData
- Notification feedback system

### Fixed
- Memory leak in DataManager
- Crash when deleting transaction

### Changed
- Improved category matching algorithm
- Updated UI design for transaction list
```
