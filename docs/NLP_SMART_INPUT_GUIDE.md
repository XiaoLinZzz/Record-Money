# NLP 智能输入功能指南

## 功能概述

NLP 智能输入功能使用 Apple NaturalLanguage Framework 进行自然语言解析，支持：
- 💬 自然语言描述交易
- 🤖 智能提取交易信息
- ⚡ 快速记账体验
- 🎯 自动分类推荐
- 🌏 支持中文自然语言
- 🔒 完全离线，隐私安全

## 支持的输入格式

### 基本格式
- "今天中午星巴克花了35块"
- "昨天打车20元"
- "淘宝买了件衣服199"
- "下午肯德基花了45"
- "早上买咖啡35.5元"

### 金额识别
支持多种金额表达方式：
- ✅ `35元` / `35块` / `35rmb`
- ✅ `¥35` / `￥35`
- ✅ `35.50元` / `35.5块`
- ✅ `花了35` / `买了35`

### 商家识别
自动提取商家名称：
- ✅ "星巴克" / "麦当劳" / "肯德基"
- ✅ "淘宝" / "京东" / "美团"
- ✅ "滴滴" / "地铁" / "公交"
- ✅ 任意品牌或商家名称

### 时间识别
支持相对和绝对时间：
- ✅ `今天` / `今日` / `刚才` / `刚刚`
- ✅ `昨天` / `昨日`
- ✅ `前天` / `大前天`
- ✅ `上午` / `中午` / `下午` / `晚上`

### 分类自动推断
基于关键词自动推断分类：

| 分类 | 关键词示例 |
|------|-----------|
| 餐饮 | 吃、餐、饭、星巴克、咖啡、奶茶、火锅、外卖 |
| 交通 | 打车、滴滴、出租、地铁、公交、加油、停车 |
| 购物 | 买、购、淘宝、京东、衣服、鞋、包 |
| 娱乐 | 电影、KTV、游戏、唱歌 |
| 医疗 | 医院、药、看病、体检 |
| 教育 | 书、课程、培训、学费 |
| 生活 | 房租、水费、电费、网费 |

### 交易类型识别
自动判断收入或支出：
- **支出**（默认）: 花、买、付、消费
- **收入**: 收入、赚、工资、奖金、红包、报销、退款

## 功能实现文件

### 核心服务
- `AutoBookkeeping/Services/NLPParser.swift` - NaturalLanguage Framework 封装
  - 金额提取（正则表达式）
  - 商家识别（命名实体识别 + 词性标注）
  - 分类推断（关键词匹配）
  - 时间解析（相对时间计算）
  - 置信度评估

### UI 视图
- `AutoBookkeeping/Views/Transaction/SmartInputView.swift` - 智能输入主界面
- `AutoBookkeeping/Views/Transaction/ConfirmSmartInputView.swift` - 确认界面

### 集成点
- `AutoBookkeeping/Views/Transaction/TransactionListView.swift` - 工具栏智能输入按钮

## 使用流程

1. 用户点击交易列表右上角的 **智能输入按钮** (✨)
2. 输入自然语言描述（例如："今天中午星巴克花了35块"）
3. 点击"解析"或直接提交
4. 系统实时解析显示：
   - 金额：¥35.00
   - 商家：星巴克
   - 分类：餐饮
   - 时间：今天 12:00
   - 类型：支出
   - 置信度：90%
5. 确认并补充信息
6. 保存到交易记录

## 置信度评分

系统会对解析结果进行置信度评估：

| 置信度 | 图标 | 颜色 | 说明 |
|--------|------|------|------|
| 80%-100% | ✅ | 绿色 | 高置信度，可直接保存 |
| 50%-79% | ⚠️ | 橙色 | 中等置信度，建议检查 |
| 0%-49% | ❌ | 红色 | 低置信度，需要补充信息 |

### 置信度计算规则
- **金额识别** - 40% 权重
- **商家识别** - 30% 权重
- **分类识别** - 20% 权重
- **时间识别** - 10% 权重

## 常见问题

### Q: 识别失败怎么办？
A: 确保输入包含：
- 明确的金额（数字 + 单位）
- 可识别的商家或场景
- 尽量使用完整描述

### Q: 识别结果不准确？
A: NLP 解析后会进入确认界面，可以手动修正：
- 金额
- 商家名称
- 交易分类
- 日期时间

### Q: 支持哪些语言？
A: 当前主要支持中文自然语言描述，未来将扩展英文支持。

### Q: 是否需要网络连接？
A: 完全不需要！所有 NLP 处理都在设备本地完成。

### Q: 和 OCR 扫描有什么区别？
A:
- **智能输入**: 用户主动描述交易，适合快速记账
- **OCR 扫描**: 识别小票图片，适合有实体小票的场景

## 技术实现细节

### 商家识别算法
1. 使用 NLTagger 进行命名实体识别
2. 使用 NSLinguisticTagger 进行词性标注
3. 过滤时间、金额等关键词
4. 优先选择专有名词

### 分类推断算法
1. 维护分类关键词字典
2. 遍历输入文本匹配关键词
3. 返回第一个匹配的分类
4. 未匹配则由智能分类引擎推荐

### 时间解析算法
1. 优先匹配相对时间关键词（今天、昨天等）
2. 识别时段关键词（上午、下午等）
3. 计算具体日期时间
4. 默认当前时间
