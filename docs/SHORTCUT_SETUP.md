## 🚀 完整配置步骤

### 第一步：创建快捷指令

#### 1.1 打开快捷指令 App

```
在 iPhone 主屏幕找到"快捷指令" App
如果没有，从 App Store 下载（iOS 系统自带）
```

#### 1.2 创建新的快捷指令

```
1. 点击底部"快捷指令"标签（不是"自动化"）
2. 点击右上角 "+" 号
3. 点击"添加操作"
```

#### 1.3 设置快捷指令名称

```
1. 点击顶部的"新快捷指令"
2. 修改名称为："快速记账" 或你喜欢的名称
3. 选择一个图标（可选）
```

### 第二步：添加操作

按顺序添加以下操作：

#### 操作 1：等待（让支付页面稳定）

```
• 搜索框输入："等待"
• 点击"等待"操作
• 时间设置为：0.5 秒
```

💡 **作用**：确保支付成功页面完全显示，OCR 识别更准确

#### 操作 2：截图

```
• 搜索："截图"
• 点击"对屏幕截图"
```

💡 **作用**：捕获当前显示的支付成功页面

#### 操作 3：OCR 文本识别

```
• 搜索："获取文本"
• 点击"从图像获取文本"
• 输入选择："屏幕截图"
```

💡 **作用**：使用 iOS 的 Live Text 技术，识别图片中的所有文字

#### 操作 4：判断是否为支付页面

```
• 搜索："if"
• 点击"如果"
• 设置条件：
  - 输入："文本"（选择上一步的识别文本）
  - 条件："包含"
  - 值："支付成功"
```

💡 **作用**：智能判断，只在真正支付时记账，避免误触发

#### 操作 5-8：提取信息并记账（在 if 内部）

在"如果"和"否则"之间添加以下操作：

**5. 提取金额**

```
• 搜索："匹配文本"
• 点击"匹配文本"
• 文本：选择"识别的文本"
• 模式：¥?(\d+\.?\d+)
• ✅ 勾选"正则表达式"
```

**6. 提取商家名称**

```
• 再次添加"匹配文本"
• 文本：选择"识别的文本"
• 模式：向(.+?)付款|收款方[:：]\s*(.+)
• ✅ 勾选"正则表达式"
```

**7. 智能判断支付方式**

```
• 添加"如果"
• 条件："识别的文本" 包含 "微信"
• 如果是：
  - 添加"设定变量"
  - 变量名："支付方式"
  - 值："微信支付"
• 否则：
  - 添加"设定变量"
  - 变量名："支付方式"
  - 值："支付宝"
```

**8. 调用 App Intent**

```
• 搜索："添加交易记录"
• 选择"无感记账 - 添加交易记录"
• 配置参数：
  - 金额：选择"匹配的文本"（第一个匹配结果）
  - 商家名称：选择"匹配的文本"（第二个匹配结果）
    如果为空，输入："未知商家"
  - 交易类型：选择"支出"
  - 原始文本：选择"识别的文本"
  - 支付方式：选择变量"支付方式"
```

#### 操作 9：添加成功提示（在 if 内部）

```
• 搜索："显示通知"
• 标题："✅ 记账成功"
• 正文：
  商家: [匹配的商家]
  金额: ¥[匹配的金额]
```

#### 操作 10：添加失败提示（在 else 内部）

```
• 在"否则"后面添加"显示通知"
• 标题："⚠️ 未识别到支付信息"
• 正文："请确保在支付成功页面按按钮，或手动记账"
```

#### 操作 11：清理截图

```
• 在"结束 如果"后面
• 搜索："删除照片"
• 选择"删除照片"
• 照片：选择"屏幕截图"
• ✅ 关闭"显示删除确认"
```

💡 **作用**：自动清理临时截图，不占用相册空间

### 第三步：配置操作按钮

#### 3.1 打开设置

```
设置 → 操作按钮
```

#### 3.2 选择快捷指令

```
1. 在操作按钮配置页面
2. 左右滑动，找到"快捷指令"图标
3. 点击"选择快捷指令"
4. 选择刚才创建的"快速记账"
5. 完成！
```

## 🔧 正则表达式说明

### 金额匹配

| 模式 | 说明 | 匹配示例 |
|-----|------|---------|
| `¥?(\d+\.?\d+)` | 基础匹配（推荐） | ¥35.00, 35.00, 35 |
| `¥(\d+\.\d{2})` | 严格两位小数 | ¥35.00 |
| `[¥￥](\d{1,6}(?:\.\d{2})?)` | 限制范围+兼容全角 | ¥0.01~¥999999.99 |

### 商家匹配

| 模式 | 说明 | 匹配示例 |
|-----|------|---------|
| `向(.+?)付款` | 微信常用格式 | "向星巴克付款" → 星巴克 |
| `收款方[:：]\s*(.+)` | 微信详情格式 | "收款方: 星巴克" → 星巴克 |
| `商家[:：]\s*(.+)` | 支付宝格式 | "商家: 星巴克" → 星巴克 |
| `转账给(.+?)\s` | 转账格式 | "转账给张三" → 张三 |

### 组合匹配（推荐）

```
向(.+?)付款|收款方[:：]\s*(.+)|商家[:：]\s*(.+)
```

这个模式可以匹配多种格式，提高成功率。

## ⚠️ 常见问题

### Q1: 按了按钮但没反应

**可能原因**：
- 操作按钮未配置为快捷指令
- 快捷指令未选择正确

**解决方案**：
```
1. 设置 → 操作按钮
2. 确认选择的是"快捷指令"
3. 确认选择的是"快速记账"这个快捷指令
```

### Q2: 提示"未识别到支付信息"

**可能原因**：
- 按按钮时不在支付成功页面
- 支付页面文本格式不同
- OCR 识别失败

**解决方案**：
```
1. 确保在支付成功页面显示时按按钮
2. 可以稍等 1-2 秒，让页面完全显示
3. 如果始终识别不到，进行调试（见下文）
```

### Q3: 提取到的金额或商家不对

**可能原因**：
- 正则表达式匹配到了错误的文本
- 页面上有多个金额

**解决方案**：
```
调整正则表达式，使其更精确：

金额：
¥([1-9]\d{0,5}\.\d{2}|0\.\d{2})

说明：
- 必须以 ¥ 开头
- 排除 0 元
- 必须有两位小数
```

### Q4: 每次都需要手动删除截图

**检查清单**：
- [ ] 是否添加了"删除照片"操作
- [ ] 是否关闭了"显示删除确认"

### Q5: 操作按钮已经有其他用途

**方案 A - 聚焦模式**：
```
1. 创建"记账"聚焦模式
2. 在该模式下，操作按钮触发"快速记账"
3. 需要记账时切换聚焦模式
```

**方案 B - 使用 Widget**：
```
在主屏幕添加"快速记账"Widget
点击 Widget 触发同样的快捷指令
```

**方案 C - Siri 语音**：
```
"嘿 Siri，快速记账"
```

### Q6: 权限提示

**首次运行时**：
```
1. 允许访问相册 ✅
2. 允许访问剪贴板 ✅
3. 勾选"始终允许" ✅
```

**如果每次都询问**：
```
设置 → 快捷指令 → 专用访问权限
→ 允许访问照片 ✅
→ 允许访问剪贴板 ✅
```

### 方法 1：查看识别的文本

在"从图像获取文本"后添加：

```
添加到备忘录
标题: OCR调试
内容:
  时间: [当前日期]
  识别文本: [识别的文本]
```

支付一次，然后查看备忘录，看看实际识别到了什么。

在每个"匹配文本"后添加：

```
显示通知
标题: 匹配结果
正文: [匹配的文本]
```

这样可以看到正则表达式匹配到了什么。

```
  1. 对屏幕截图
```

看OCR是否正确。

**Step 3: 测试匹配**
```
添加匹配操作，用显示通知查看结果
```

```
运行完整流程
```

## 🎓 进阶技巧

### 技巧 1：过滤小额支付

避免记录红包、小额转账等：

```
在调用 Intent 前添加：
如果 匹配的金额 < 1
  显示通知 "金额太小，未记账"
否则
  调用 Intent
```

### 技巧 2：自动判断收入/支出

```
如果 文本 包含 "收款" 或 "转入"
  类型 = 收入
否则
  类型 = 支出
```

### 技巧 3：提取备注信息

如果支付时有备注：

```
匹配文本
模式: 备注[:：]\s*(.+)
```

将匹配结果传入 Intent 的备注字段。

### 技巧 4：支持更多支付方式

```
如果 文本 包含 "微信"
  支付方式 = "微信支付"
否则 如果 文本 包含 "支付宝"
  支付方式 = "支付宝"
否则 如果 文本 包含 "云闪付"
  支付方式 = "云闪付"
否则
  支付方式 = "其他"
```

## 🔐 隐私与安全

### 数据处理流程

```
支付页面（在你的 iPhone 上）
    ↓ 本地截图
iPhone 相册（临时）
    ↓ 本地 OCR
快捷指令（iOS 系统级）
    ↓ 本地提取
无感记账 App（本地调用）
    ↓ 本地存储
iPhone 数据库
    ↓ 立即删除
临时截图被删除
```

**保证**：
- ✅ 所有处理都在本地完成
- ✅ 不上传任何数据到服务器
- ✅ 临时截图自动删除
- ✅ 数据只存在你的设备上

### 权限说明

| 权限 | 用途 | 是否必需 |
|-----|------|---------|
| 照片访问 | 截图和 OCR | ✅ 必需 |
| 剪贴板 | 数据传递 | ✅ 必需 |
| 通知 | 结果反馈 | ⭕ 推荐 |
