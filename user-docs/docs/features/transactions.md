记账是 AutoBookkeeping 的核心功能。本指南将详细介绍如何管理你的交易记录。

## ➕ 添加交易

有多种方式可以添加新的交易记录。

### 方式一：快捷指令（推荐）⚡

这是最快的记账方式：

1. **完成支付** - 在微信/支付宝完成付款
2. **停留在结果页** - 不要退出支付结果页面
3. **触发快捷指令**
   - iPhone 15 Pro: 按操作按钮
   - 其他机型: 轻点背面或使用 Siri
4. **自动完成** - 快捷指令自动运行并创建记录

**耗时**：约 2-3 秒 ⚡

详细教程：[快速记账教程](/tutorials/quick-add)

### 方式二：手动添加

点击右下角的 **[+]** 按钮：

1. **选择类型**
   - 💸 支出（红色）
   - 💰 收入（绿色）

2. **填写信息**

| 字段 | 说明 | 示例 |
|------|------|------|
| 💵 金额 | 必填，支持小数 | 35.00 |
| 🏪 商家 | 可选，商家名称 | 麦当劳 |
| 📁 分类 | 必填，点击选择 | 餐饮美食 |
| 🕐 时间 | 默认当前，可修改 | 今天 12:30 |
| 📝 备注 | 可选，额外说明 | 和同事聚餐 |

3. **保存**
   - 点击 **保存** 按钮
   - 或点击 **取消** 放弃添加

**耗时**：约 15-30 秒

### 方式三：智能输入 🎯

使用自然语言快速记账：

1. 点击 **[+]** 按钮
2. 点击 **智能输入** 图标（🎤）
3. 说出或输入交易描述：

**示例输入**：
```
今天中午在麦当劳花了35块吃午饭
```

**自动解析**：
- 💵 金额: 35.00
- 🏪 商家: 麦当劳
- 📁 分类: 餐饮美食
- 🕐 时间: 今天中午
- 📝 备注: 午饭

4. 确认信息无误后保存

**耗时**：约 5-10 秒

详细教程：[智能输入教程](/tutorials/smart-input)

### 方式四：扫描小票 📸

通过拍照识别小票信息：

1. 点击 **[+]** 按钮
2. 点击 **扫描** 图标（📷）
3. 对准小票拍照
4. AI 自动识别信息
5. 确认后保存

**支持的小票类型**：
- 🏪 超市购物小票
- 🍜 餐厅账单
- 🚖 出租车票据
- 🏥 医疗发票

**耗时**：约 8-15 秒

详细教程：[扫描小票教程](/tutorials/scan-receipt)

## ✏️ 编辑交易

### 快速编辑

在列表页面向左滑动交易卡片：

```
┌─────────────────────────────────┐
│ 🍜 午饭         -¥35.00  [编辑] │← 向左滑
│ 麦当劳 · 12:30          [删除] │
└─────────────────────────────────┘
```

点击 **编辑** 进入编辑模式。

### 完整编辑

1. 进入交易详情页
2. 点击右上角 **编辑**
3. 修改需要更改的字段
4. 点击 **保存** 或 **取消**

::: tip 编辑提示
- ✏️ 可以修改任意字段
- 🕐 时间可以精确到分钟
- 📁 分类更改后会影响统计数据
- 💡 建议及时修正错误的记录
:::

## 🗑️ 删除交易

### 单个删除

**方式一：滑动删除**
- 在列表中向左滑动
- 点击红色 **删除** 按钮
- 确认删除

**方式二：详情页删除**
- 进入交易详情
- 点击 **删除** 按钮
- 确认删除

### 批量删除

1. 在列表页点击右上角 **选择**
2. 勾选要删除的交易
3. 点击底部 **删除** 按钮
4. 确认批量删除

::: warning 删除警告
删除操作不可恢复！建议在删除前：
- ✅ 确认是否需要导出数据
- ✅ 检查是否选中了正确的记录
- ✅ 考虑使用"隐藏"而非删除（未来功能）
:::

## 🔍 搜索与筛选

找到特定的交易记录。

### 快速搜索

1. 在列表页点击顶部 **搜索框**
2. 输入关键词：
   - 商家名称（如"麦当劳"）
   - 金额（如"35"）
   - 备注内容
3. 实时显示搜索结果

### 高级筛选

点击右上角 **筛选** 图标，可按以下条件筛选：

**时间范围**
- 今天
- 本周
- 本月
- 自定义日期范围

**交易类型**
- 全部
- 仅支出
- 仅收入

**分类筛选**
- 选择一个或多个分类
- 支持多选

**金额范围**
- 最小金额
- 最大金额

**排序方式**
- 时间（从新到旧）
- 时间（从旧到新）
- 金额（从高到低）
- 金额（从低到高）

### 筛选示例

**查找本月所有餐饮消费**：
- 时间：本月
- 分类：餐饮美食
- 类型：支出

**查找大额支出**：
- 类型：支出
- 金额：≥ 100
- 排序：金额从高到低

## 💡 使用技巧

### 提高效率

1. **使用快捷指令** - 支付后立即记账，不会忘记
2. **善用智能输入** - 语音或打字都比填表单快
3. **设置默认分类** - 常用分类放在前面
4. **利用搜索功能** - 快速找到历史记录

### 保持准确

1. **及时记账** - 不要积累太多待记录的消费
2. **检查分类** - AI 可能出错，及时修正
3. **添加备注** - 重要消费添加备注方便回忆
4. **定期检查** - 每周查看一次，确保没有遗漏

### 数据分析

1. **查看趋势** - 对比不同月份的消费
2. **关注大额** - 找出可以节省的地方
3. **分类统计** - 了解钱主要花在哪里
4. **设置预算** - 根据历史数据合理设置预算

## ⚙️ 交易设置

在 **设置** 页面可以配置交易相关选项。

### 默认设置

- **默认交易类型** - 支出 / 收入
- **默认分类** - 新记录的默认分类
- **默认时间** - 当前时间 / 支付时间
- **自动分类** - 是否启用 AI 自动分类

### 显示设置

- **列表样式** - 紧凑 / 宽松
- **金额格式** - 显示千分位、小数位数
- **日期格式** - 显示方式
- **分组方式** - 按日期 / 按分类
