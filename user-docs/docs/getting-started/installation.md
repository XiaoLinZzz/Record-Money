# 下载与安装

欢迎使用 AutoBookkeeping！本指南将帮助你快速完成应用的下载和安装。

## 📱 系统要求

在安装之前，请确保你的设备满足以下要求：

| 项目 | 要求 |
|------|------|
| **操作系统** | iOS 16.0 或更高版本 |
| **推荐系统** | iOS 17.0+ (可使用完整功能) |
| **设备** | iPhone (不支持iPad) |
| **存储空间** | 至少 50 MB 可用空间 |
| **推荐设备** | iPhone 15 Pro (支持操作按钮) |

::: tip 提示
虽然应用支持 iOS 16.0+，但我们强烈推荐使用 iOS 17.0 或更高版本以获得最佳体验。
:::

## 🏪 下载方式

### 方式一：App Store 下载（推荐）

> 🚧 **注意**：应用目前正在开发中，尚未上架 App Store

待应用上架后，你可以通过以下步骤下载：

1. 打开 iPhone 上的 **App Store**
2. 点击底部的 **搜索** 标签
3. 在搜索框中输入 **"AutoBookkeeping"** 或 **"无感记账"**
4. 找到应用后，点击 **获取** 按钮
5. 使用 Face ID / Touch ID 或输入密码确认下载
6. 等待下载和安装完成

### 方式二：TestFlight 测试版（开发者）

如果你想体验最新的测试版本：

1. 首先下载并安装 **TestFlight** 应用（来自 App Store）
2. 从开发者处获取测试邀请链接
3. 在 Safari 中打开邀请链接
4. 点击 **开始测试** 按钮
5. 在 TestFlight 中找到 AutoBookkeeping
6. 点击 **安装** 按钮

::: warning 测试版注意事项
- 测试版可能包含未修复的 Bug
- 功能可能不稳定
- 数据可能在更新时丢失，请注意备份
:::

### 方式三：从源码构建（开发者）

如果你是开发者，可以从 GitHub 源码构建：

```bash
# 1. 克隆仓库
git clone https://github.com/XiaoLinZzz/Record-Money.git

# 2. 进入项目目录
cd Record-Money

# 3. 使用 Xcode 打开项目
open AutoBookkeeping.xcodeproj

# 4. 在 Xcode 中选择你的设备并运行
```

详细的开发者指南请查看 [GitHub 仓库](https://github.com/XiaoLinZzz/Record-Money)。

## 📲 安装过程

### 自动安装

从 App Store 或 TestFlight 安装时，系统会自动处理所有步骤：

1. **下载应用包** - 约 20-30 MB
2. **验证签名** - 确保应用来源可信
3. **安装到设备** - 自动创建应用图标
4. **配置权限** - 首次启动时会请求必要权限

### 安装完成标志

安装成功后，你会看到：

- ✅ 主屏幕上出现 AutoBookkeeping 图标
- ✅ 图标为绿色钱包样式（💰）
- ✅ 应用大小约为 25-35 MB

## 🔐 权限说明

首次启动应用时，可能会请求以下权限：

### 必需权限

| 权限 | 用途 | 时机 |
|------|------|------|
| **通知** | 发送记账成功通知、预算提醒 | 首次启动 |
| **相机** | 扫描小票（可选功能） | 使用小票扫描时 |
| **照片库** | 保存和识别支付截图 | 使用快捷指令时 |

### 可选权限

| 权限 | 用途 | 时机 |
|------|------|------|
| **Siri 与搜索** | 启用语音记账功能 | 设置快捷指令时 |
| **面容ID/触控ID** | 保护隐私数据 | 在设置中启用时 |

::: info 隐私承诺
- 📱 所有数据仅存储在本地
- 🔒 不会上传到任何服务器
- 🚫 不会收集个人信息
- ✅ 照片仅用于识别后立即删除
:::

## ⚙️ 首次配置

安装完成后，建议立即进行以下配置：

1. **启动应用** - 点击主屏幕图标
2. **完成引导** - 跟随新手引导了解功能

## ❓ 常见安装问题

### 无法下载应用

**问题**：点击"获取"后没有反应或下载失败

**解决方案**：
1. 检查网络连接是否正常
2. 确认 App Store 账号已登录
3. 检查设备存储空间是否充足
4. 尝试重启 App Store 应用
5. 重启 iPhone

### 提示"此应用不兼容"

**问题**：显示应用与设备不兼容

**解决方案**：
1. 检查 iOS 版本是否为 16.0 或更高
2. 前往 **设置 → 通用 → 软件更新** 升级系统
3. 确认设备为 iPhone（不支持 iPad）

### 安装后无法打开

**问题**：点击图标后应用崩溃或闪退

**解决方案**：
1. 完全卸载应用后重新安装
2. 重启设备
3. 确认系统版本满足要求
4. 检查是否有系统更新
5. 如问题持续，请 [提交反馈](https://github.com/XiaoLinZzz/Record-Money/issues)

## 🔄 更新应用

### 自动更新（推荐）

1. 打开 **设置**
2. 点击 **App Store**
3. 启用 **App 更新**

### 手动更新

1. 打开 **App Store**
2. 点击右上角的 **头像**
3. 向下滚动到 **可用更新**
4. 找到 AutoBookkeeping 并点击 **更新**

::: tip 保持更新
我们定期发布新功能和Bug修复，建议开启自动更新以获得最佳体验。
:::
