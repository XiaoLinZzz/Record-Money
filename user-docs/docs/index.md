## 🚀 为什么选择 AutoBookkeeping？

传统记账应用需要打开App、填写表单、选择分类...整个流程繁琐耗时。**AutoBookkeeping** 通过深度集成iOS系统特性，将记账时间从30秒缩短至2秒。

### 💡 核心理念

> **无感记账** - 让记账成为一个不需要思考的习惯

- **快**: 支付完成后按一下按钮，自动完成记录
- **准**: AI智能分类，准确率高达95%+
- **简**: 一键配置快捷指令，无需复杂设置
- **安全**: 所有处理在本地，数据永不离开你的设备

## 🎯 适用场景

| 场景 | 传统方式 | AutoBookkeeping |
|------|---------|----------------|
| 超市购物 | 回家后凭记忆记账 | 付款后按按钮，立即记录 |
| 外卖点餐 | 需要打开App填写 | 支付页面直接记账 |
| 交通出行 | 经常忘记记账 | 自动截图识别金额 |
| 日常消费 | 每天花10分钟整理 | 全天累计仅需10秒 |

## 🌟 主要特性

### 极速记账
- 📱 iPhone 15 Pro操作按钮一键触发
- 🗣️ Siri语音指令记账
- 🔘 轻点背面触发（其他机型）
- 🧩 桌面小组件快速添加

### 智能功能
- 🤖 AI自动分类（基于CoreML）
- 📸 小票扫描（OCR识别）
- 💬 自然语言输入（"今天午饭花了35块"）
- 🎯 智能商家识别

### 数据管理
- 📊 多维度统计分析
- 💰 预算管理与提醒
- 📈 收支趋势可视化
- 💾 iCloud自动同步

### 隐私保护
- 🔒 本地数据加密存储
- 🚫 无需联网，完全离线
- 🗑️ 临时截图自动删除
- 🔐 支持面容ID/触控ID
