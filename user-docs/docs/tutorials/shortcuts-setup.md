# 快捷指令设置

本教程详细介绍如何配置 AutoBookkeeping 的快捷指令，这是实现"无感记账"的关键步骤。

## 🎯 为什么需要快捷指令

传统记账需要：
1. 打开 App
2. 点击添加
3. 填写表单
4. 选择分类
5. 保存

**耗时**：约 30 秒

使用快捷指令后：
1. 按一下按钮
2. 完成！

**耗时**：约 2 秒 ⚡

**效率提升 15 倍！**

## 📋 前置准备

开始之前，请确保：

- [x] iPhone 已升级到 iOS 16.0+（推荐 iOS 17.0+）
- [x] 已安装 AutoBookkeeping 应用
- [x] 系统自带的"快捷指令" App 已安装（通常预装）

::: tip 快捷指令 App
如果找不到快捷指令 App，可以从 App Store 免费下载：
[快捷指令 - Apple](https://apps.apple.com/app/id915249334)
:::

## 🚀 配置方式

提供两种配置方式，推荐使用方式一。

### 方式一：一键添加（推荐）⭐

最简单快捷的配置方式，只需几次点击。

#### 步骤详解

<div class="tutorial-steps">

**步骤 1：打开 AutoBookkeeping**
- 启动 AutoBookkeeping 应用
- 如果是首次使用，会自动显示引导页
- 如果已使用过，进入 **设置** 标签

**步骤 2：进入快捷指令设置**
- 在设置页面找到 **快捷指令配置**
- 或在引导页面点击 **立即配置**

**步骤 3：点击"一键添加快捷指令"**
- 点击蓝色按钮 **"一键添加快捷指令"**
- 系统会自动跳转到快捷指令 App

**步骤 4：添加快捷指令**
- 系统显示快捷指令预览
- 向下滚动查看快捷指令流程
- 点击底部的 **"添加快捷指令"** 按钮
- 等待几秒钟，快捷指令添加完成

**步骤 5：验证安装**
- 返回 AutoBookkeeping
- 设置页面应显示 **"✅ 已配置"**
- 或打开快捷指令 App 查看是否有 "AutoBookkeeping 记账"

</div>

::: tip 成功标志
- ✅ 快捷指令 App 中看到 "AutoBookkeeping 记账"
- ✅ AutoBookkeeping 设置页显示"已配置"
- ✅ 快捷指令图标为 AutoBookkeeping 的绿色图标
:::

### 方式二：手动创建

如果一键添加失败，可以手动创建快捷指令。

#### 准备工作

1. 打开 **快捷指令** App
2. 点击右上角 **[+]** 按钮
3. 选择 **添加操作**

#### 配置步骤

**1. 获取最新照片**

```
搜索：获取最新照片
添加操作：获取最新照片
设置：
  - 照片数量：1 张照片
  - 包括：截图
```

**2. 运行 App Intent**

```
搜索：App
添加操作：运行 AutoBookkeeping 的 Intent
选择：Quick Add Expense（快速添加支出）
参数：
  - Screenshot: 最新照片（从上一步获取）
```

**3. 删除截图**

```
搜索：删除照片
添加操作：删除照片
设置：
  - 确认删除：关闭
  - 照片：最新照片
```

**4. 显示通知**

```
搜索：显示通知
添加操作：显示通知
设置：
  - 标题：记账成功
  - 正文：交易已保存
```

**5. 保存快捷指令**

```
点击右上角完成
命名：AutoBookkeeping 记账
图标：选择 AutoBookkeeping 图标
完成！
```

::: details 详细截图教程
由于手动创建较为复杂，建议使用一键添加方式。如需详细图文教程，请查看官方文档或联系支持。
:::

## 📲 设置触发方式

配置好快捷指令后，需要设置如何触发它。

### iPhone 15 Pro / 16 Pro - 操作按钮⭐

这是最推荐的触发方式，速度最快！

#### 配置步骤

1. 打开 iPhone **设置** 应用
2. 向下滚动，找到 **操作按钮**
3. 点击进入操作按钮设置
4. 选择 **快捷指令** 选项
5. 点击 **选择快捷指令**
6. 在列表中找到 **"AutoBookkeeping 记账"**
7. 选择并确认

#### 使用方法

- 位置：iPhone 左侧，音量键上方的橙色按钮
- 操作：短按一下（约 0.5 秒）
- 反馈：震动 + 快捷指令运行

::: tip 操作按钮优势
- ⚡ 最快（< 1 秒触发）
- 🎯 单手操作
- 🔒 锁屏也可用
- 💪 即使戴手套也能按
:::

### 所有机型 - 轻点背面

iPhone 8 及以后的机型都支持。

#### 配置步骤

1. 打开 **设置 → 辅助功能**
2. 选择 **触控**
3. 选择 **轻点背面**
4. 选择 **轻点两下** 或 **轻点三下**
5. 向下滚动找到快捷指令部分
6. 选择 **"AutoBookkeeping 记账"**

#### 使用方法

- 位置：iPhone 背面 Apple Logo 附近
- 操作：快速轻点两下或三下
- 力度：适中，不要太重或太轻

::: warning 注意事项
- 带手机壳时可能不灵敏
- 某些姿势下可能误触
- 需要一定练习
:::

**建议**：
- 两下：日常使用，误触少
- 三下：更准确，但速度稍慢

### 所有机型 - Siri 语音

最传统但最可靠的方式。

#### 自动语音触发

直接对 Siri 说：

> "嘿 Siri，AutoBookkeeping 记账"

Siri 会自动运行快捷指令。

#### 自定义语音短语

设置更短的触发语：

1. 打开 **快捷指令** App
2. 长按 **"AutoBookkeeping 记账"** 快捷指令
3. 点击 **详细信息**（ℹ️）
4. 点击 **添加到 Siri**
5. 点击 **录制短语**
6. 说出你想用的短语，如：
   - "记一笔"
   - "记账"
   - "花钱了"
7. 点击 **完成**

现在你可以说"嘿 Siri，记一笔"来触发！

::: tip Siri 优势
- 🗣️ 解放双手
- 📱 所有机型通用
- 🚗 开车时可用
- 🔒 锁屏也能用
:::

## 🧪 测试快捷指令

配置完成后，一定要测试！

### 测试步骤

1. **准备测试环境**
   - 打开任意 App（如微信、支付宝）
   - 找一张有金额的图片或截图
   - 或直接截图当前屏幕

2. **触发快捷指令**
   - 使用你配置的触发方式
   - iPhone 15 Pro：按操作按钮
   - 其他机型：轻点背面或呼叫 Siri

3. **观察运行**
   - 应该看到快捷指令在运行
   - 可能有短暂的加载动画
   - 注意是否有错误提示

4. **检查结果**
   - 应收到"记账成功"通知
   - 打开 AutoBookkeeping
   - 在交易列表中应该看到新记录

### 成功标志

- ✅ 收到系统通知："记账成功"
- ✅ AutoBookkeeping 中出现新记录
- ✅ 金额正确识别
- ✅ 临时截图已自动删除

### 失败排查

如果测试失败，请检查：

1. ✅ 快捷指令是否正确添加
2. ✅ AutoBookkeeping 是否已授予照片权限
3. ✅ 通知权限是否已开启
4. ✅ 快捷指令中的 App Intent 是否选对
5. ✅ 是否有错误提示信息

详见：[故障排除](/faq/troubleshooting)

## ⚙️ 高级设置

### 自定义快捷指令

你可以根据需要修改快捷指令：

**添加确认步骤**：
```
在"运行 App Intent"之前添加：
- 显示提醒：是否记录这笔消费？
- 如果选择"是"，继续
```

**添加默认分类**：
```
修改 App Intent 参数：
- Category: 餐饮美食（或其他默认分类）
```

**批量记账**：
```
添加循环：
- 重复 5 次
- 每次获取一张照片并处理
```

### 多个快捷指令

你可以创建多个版本：

**AutoBookkeeping - 餐饮**
- 默认分类：餐饮美食
- 用于饭店吃饭

**AutoBookkeeping - 交通**
- 默认分类：交通出行
- 用于坐车出行

**AutoBookkeeping - 购物**
- 默认分类：购物消费
- 用于网购实体店

每个快捷指令绑定不同的触发方式。

## 💡 使用技巧

### 提高识别准确率

1. **确保金额可见**
   - 截图时确保支付金额清晰显示
   - 避免弹窗遮挡关键信息

2. **等待加载完成**
   - 支付页面完全加载后再触发
   - 不要在"加载中"时截图

3. **保持屏幕亮度**
   - 亮度太低会影响 OCR 识别
   - 建议保持 50% 以上亮度

### 批量补记

如果忘记及时记账：

1. 从微信/支付宝导出账单截图
2. 逐一打开截图
3. 在截图查看时触发快捷指令
4. 快速完成批量记账

### 离线使用

快捷指令完全离线运行：

- ✅ 无需网络
- ✅ 所有处理在本地
- ✅ 飞行模式也能用

## ❓ 常见问题

### 找不到 AutoBookkeeping 的 Intent？

**原因**：App 未正确安装或需要重启

**解决**：
1. 确认 AutoBookkeeping 已安装
2. 打开一次 AutoBookkeeping
3. 重启 iPhone
4. 重新尝试添加

### 快捷指令运行失败？

**可能原因**：
- 照片权限未授予
- App Intent 选择错误
- 系统版本过低

**解决方法**：
1. 检查 **设置 → 隐私 → 照片** 中 AutoBookkeeping 的权限
2. 确认 iOS 版本 ≥ 16.0
3. 重新添加快捷指令

### 没有收到通知？

**检查**：
1. **设置 → 通知 → AutoBookkeeping** 是否允许通知
2. 勿扰模式是否开启
3. 通知样式是否为"无"

### 操作按钮没有快捷指令选项？

**原因**：设备不支持

**说明**：
- 仅 iPhone 15 Pro / 16 Pro 有操作按钮
- 其他机型请使用轻点背面或 Siri
